# SEETO COMMUNICATION LIMITED

Company website for [SEETO](https://seeto.app) — a Nairobi technology company building Rayso, Seeto Exchange, Marhaba and Seeto Systems.

## Stack

TanStack Start, React, Tailwind CSS, Vite.

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
